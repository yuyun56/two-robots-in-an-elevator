One line of awkward small talk between two robots sharing an elevator: a pickup line the speaker's own route log has heard 1,412 times before. The entry is the single line in entry.txt; main.ts is a small guard that validates it (one line, under 200 characters) and hands it in.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
# prints the line, its length and the budget left, and writes out/entry.txt
```
